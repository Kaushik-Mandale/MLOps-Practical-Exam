# \# Breast Cancer Classification – MLOps Project

# 

# \## Aim

# To develop an end-to-end MLOps pipeline for Breast Cancer Classification using the Wisconsin Breast Cancer Dataset, integrating DVC for data versioning, automated data pipelines, Feature Stores for feature management, and MLflow for experiment tracking and model selection, followed by pushing the project code to GitHub using Git.
